## 🚀 Featured Projects

🔹 **[IPA-GPT — Phonetic Tokenization for Multilingual LLMs](https://github.com/Kkoundinyaa/IPA_GPT)**
Pretrained GPT-2 scale models (up to 1.44B params) across 8 languages on 8x H100 GPUs using IPA-based tokenization. Validated +5.1 F1 on Polish XNLI and zero-shot Bengali transfer from 3.56 to 31.24 F1. Co-authoring EMNLP 2026 submission.

🔹 **[dhvani — Hinglish Normalization Library](https://pypi.org/project/dhvani/)**
Open source Python package on PyPI (~785 downloads/month) normalizing Hinglish text using IPA as a phonetic bridge between Devanagari and Latin scripts. `pip install dhvani`

🔹 **[SMM4H 2024 — Multilingual Adverse Drug Event Detection](https://github.com/Kkoundinyaa/XLM-FInetuning)**
3rd place overall. Fine-tuned XLM-RoBERTa on <1% positive-class data across 4 languages. 78.6% F1-macro on English, ~9x F1 improvement on Russian via SMOTE and language-specific threshold tuning.

🔹 **[Text Classification with LLM Prompt Engineering](https://github.com/Kkoundinyaa/Text-Classification-with-LLM-Prompt-Engineering)**
Zero-shot and few-shot prompt engineering for business event classification across 45 automotive firms. Lifted accuracy from 78% to 93% via chain-of-thought prompting.

🔹 **[modded-nanogpt — Custom GPT Pretraining Pipeline](https://github.com/Kkoundinyaa/modded-nanogpt)**
Modified NanoGPT-style training pipeline with custom BPE tokenizers and multilingual pretraining support across IPA and romanization representations.
